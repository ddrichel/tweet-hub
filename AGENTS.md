# Agent instructions


## Owner's main-branch rule: 18 October 2026

For the owner's authorized work, `main` is the lasting source of completed work. Prefer contained direct commits where repository rules permit them. A temporary branch is allowed only while the work is actually active; record its owner, bounded task and target checkpoint in existing repository Markdown. Integrate completed work and its original commit history into `main`, preserve later valid changes, then remove the completed branch after a fresh head/ancestry check. Finish existing pull requests autonomously when their work is ready and the required checks/reviews permit merging; do not leave a finished PR waiting for routine owner confirmation.

Preserve actual concurrent work, required protections, private data and publication boundaries. Never delete `main`, discard unique work, force-push, or reactivate retired products during cleanup. A merge is not deployment or evidence another agent has received an update. This dated owner instruction supersedes older instructions to keep inactive work branches or wait for routine merge confirmation; contributor permissions and required reviews remain in force.
